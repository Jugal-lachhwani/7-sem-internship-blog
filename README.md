# Forecasting Floods on the Ganga at Patna

7th semester internship blog (registered title: *Flood Inundation, Hydrology*), CSPIT, CHARUSAT.

Live page: https://jugal-lachhwani.github.io/7-sem-internship-blog/

Three-day water level forecasts at the Gandhighat gauge (GRU, LSTM, BiLSTM + Ridge ensemble), turned into flood maps with a Sentinel-1 inundation library, explained with SHAP and LIME, and checked against SWOT and NISAR.
